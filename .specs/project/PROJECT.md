# Obra Prime Web

## Visao

O Obra Prime Web e uma plataforma web para gestao operacional de obras da construcao civil, migrada a partir do aplicativo mobile Obra Prime originalmente desenvolvido em React Native.

O sistema deve centralizar informacoes de obras, ordens de servico, registros fotograficos, usuarios, historico de atividades, relatorios e indicadores operacionais, substituindo processos manuais, planilhas e registros fisicos.

## Objetivos

- Permitir acompanhamento gerencial e operacional de obras em tempo real.
- Reduzir dependencia de controles manuais, planilhas e documentos fisicos.
- Centralizar historico, evidencias fotograficas e status das atividades.
- Facilitar emissao de relatorios e analise de indicadores.
- Controlar acesso por usuarios e perfis.

## Usuarios-alvo

- Gestores e administradores da empresa.
- Engenheiros, supervisores ou responsaveis tecnicos.
- Equipes operacionais de campo.
- Usuarios administrativos responsaveis por acompanhamento, relatorios e controle documental.

## Escopo inicial

- Login de usuarios.
- Dashboard gerencial.
- Gestao de obras.
- Gestao de ordens de servico.
- Registro fotografico.
- Emissao de relatorios.
- Controle de usuarios.
- Historico de atividades.
- Indicadores operacionais.

## Fora do escopo inicial

- Definicao final de arquitetura tecnica.
- Integracoes externas especificas.
- Migracao automatizada de dados do aplicativo mobile.
- Aplicativo mobile novo ou manutencao do app React Native.
- Assinatura digital, financeiro, compras, estoque ou folha de pagamento, salvo decisao posterior.

## Principios de produto

- Operacional antes de decorativo: telas devem priorizar clareza, rastreabilidade e eficiencia.
- Dados auditaveis: alteracoes relevantes devem gerar historico.
- Evidencias visuais importam: fotos devem estar ligadas a obras, OS e eventos.
- Permissoes devem ser explicitas: cada perfil deve acessar apenas o necessario.
- Relatorios devem refletir dados estruturados, nao textos soltos.
